# Implementation status

## Included and implemented in this package
- FastAPI + SQLAlchemy + PostgreSQL data layer.
- Startup creation of missing tables and demo seed data.
- Career/skill catalogue and role-skill requirements.
- MCQ assessment delivery, scoring, explanations, attempt history and student skill level updates.
- Weighted career alignment and skill-gap endpoint.
- Curated resource catalogue and progress tracking.
- CSV job posting import, required-column checks, duplicate skipping and dictionary/regex skill extraction.
- Job listing and skill-demand analytics endpoints.
- React screens wired to live API data for overview, assessments, gaps, resources, job market, progress and faculty summary.

## Deliberately not represented as complete
- Production authentication, authorization and account recovery.
- A trained transformer/SkillSpan NLP model.
- Full ESCO identifier/URI import and maintained taxonomy synchronization.
- Validated psychometric question bank or hiring-grade readiness prediction.
- Time-series forecasting.
- Production deployment, monitoring, automated backups and security review.

These are explicit future research/deployment tasks. Do not claim them as implemented in academic evaluation until completed and measured.
